## Brand & Style

This design system establishes an energetic, high-velocity, high-trust workforce exchange. It combines the utilitarian clarity of dispatch infrastructure with the polished delight of consumer-grade booking.

### Visual Archetype & Posture
The aesthetic fuses **Modern Kinetic Precision** with **Tactile Glassmorphism**:
- **Zero Friction, Maximum Momentum:** Bold, deliberate layout hierarchies designed for fast scanning under bright daylight or high-stress operational environments.
- **Earned Trust:** Institutional reliability signaled through structured geometry, reinforced metadata badging, crisp tabular data, and prominent verification credentials.
- **Operational Dynamism:** High-luminance micro-accents celebrate active shifts, real-time availability, payout momentum, and immediate booking fulfillment.

### Target Audience & Tone
1. **The Modern Worker / Specialist:** Demands zero cognitive overhead, transparent earnings breakdown, instant shift capture, and dignity of work.
2. **The Consumer & Enterprise Operator:** Demands guaranteed fulfillment, verified credentialing, live telemetry, and zero transactional ambiguity.

## Colors

The palette balances deep cobalt authority against a hyper-vibrant signal emerald that represents liquidity, availability, and growth.

### Functional Roles & Distribution
- **Electric Cobalt / Deep Indigo (`#1E40AF` / `#2563EB`):** Primary brand anchor. Used for principal interface actions, selected navigation stems, system highlights, and active operational states.
- **Kinetic Emerald (`#10B981` / `#059669` / `#22C55E`):** Earning telemetry, immediate availability pings ("Instant Dispatch"), accepted offers, wallet balances, and active gig trackers.
- **Signal Amber (`#F59E0B` / `#D97706`):** High-priority alerts, urgent fill-rates, conditional verifications, and surge pricing indicators.
- **Slate Tonal Foundation (`#0F172A`, `#1E293B`, `#334155`, `#64748B`):** Governs strict typography contrast, structural borders, and dark container inversions.
- **Canvas Base (`#F8FAFC`, `#FFFFFF`, `#F1F5F9`):** Pristine, high-clarity surfaces that maintain extreme contrast ratios (minimum WCAG AA 4.5:1 across all readable metrics).

## Typography

Plus Jakarta Sans powers the entire typographic scale, providing geometric punchiness in hero sections and mechanical legibility in micro-data grids.

### Numerical Legibility & Figures
- Ensure tabular lining figures (`font-variant-numeric: tabular-nums`) are active across all payout figures, countdown timers, hourly rates, and metric cards to eliminate layout jitter during live updates.
- Micro-labels (`label-caps`) use uppercase tracking for metadata badges (`VERIFIED PRO`, `INSTANT DISPATCH`, `ESCROW SECURED`).

## Layout & Spacing

A disciplined 8pt vertical grid coupled with a responsive 12-column layout anchors all viewport configurations.

### Breakpoint Architecture
- **Mobile (< 768px):** 4-column layout with 16px (`margin-sm`) edge padding and 16px (`gutter-sm`) columns. Floating action triggers lock to safe areas above mobile bottom bars.
- **Tablet (768px - 1024px):** 8-column layout with 24px margins. Dual-pane inspection views activate for dispatch coordination.
- **Desktop (> 1024px):** 12-column layout capped at 1280px maximum content container. 32px margins with fixed sidebar or modular grid cards.

## Elevation & Depth

Visual hierarchy is maintained through subtle ambient color-tinted shadows, frosted backdrop glass layers, and crisp structural borders.

### Elevation Levels
- **Level 0 (Flat / Canvas):** Neutral `#F8FAFC` background. Elements rely on `1px solid #E2E8F0` for structure.
- **Level 1 (Resting Cards & Surfaces):** `#FFFFFF` surfaces with `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.05)` and a micro-border `rgba(226, 232, 240, 0.8)`.
- **Level 2 (Hovered Cards & Interactive Pills):** `box-shadow: 0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.04)`.
- **Level 3 (Modals, Overlays & Sticky Navbars):** Frosted glass surfaces with `background: rgba(255, 255, 255, 0.85)`, `backdrop-filter: blur(12px)`, and `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.

## Shapes

The design system utilizes smooth, ergonomic curves to deliver a friendly, human-centric aesthetic without sacrificing industrial precision.

### Geometric Rules
- Standard containers, feed items, and interactive cards default to `rounded-2xl` (`1rem`).
- Form controls, micro-metric badges, and list entries use `rounded-lg` (`0.5rem`).
- Mode toggles, filter pills, search omnibars, and verification badges use full continuous pill rounding (`rounded-full`).

## Components

### Buttons & Interactive CTAs
- **Primary Action:** Solid Electric Cobalt (`#2563EB`) with text in `#FFFFFF`. Hover shifts to `#1D4ED8`. Active state contracts subtly (`transform: scale(0.98)`).
- **Secondary / Earning CTA:** Vibrant Emerald (`#10B981`) background for payout claims, booking acceptances, and instant dispatch approvals.
- **Ghost / Outlined:** Border `1.5px solid #CBD5E1`, text `#0F172A`, hover background `#F1F5F9`.

### Dual-Mode Segmented Switch (B2C vs. B2B / Pro Mode)
- Encapsulated pill container with background `#F1F5F9` and 4px internal padding.
- Selected toggle features a white elevated pill (`#FFFFFF`) with `box-shadow: 0 2px 4px rgba(15, 23, 42, 0.08)` and bold primary text. Inactive option remains muted `#64748B`.

### Verification & Trust Badges
- **Verified Pro:** Soft cobalt tint (`#EFF6FF`), cobalt border (`#BFDBFE`), cobalt copy (`#1D4ED8`), preceded by a solid checkmark icon.
- **Instant Dispatch:** Emerald tint (`#ECFDF5`), emerald border (`#A7F3D0`), emerald copy (`#047857`), paired with an animated pulse dot.
- **GST / Enterprise Verified:** Slate tint (`#F8FAFC`), border (`#E2E8F0`), copy (`#334155`).

### Micro-Metric Stat Cards
- Enclosed in `rounded-2xl` containers with light border separation.
- Structure: Subdued tracking label (`label-caps`), dominant numerical metric (`headline-md`) using tabular figures, and a secondary trend indicator (+12% in emerald text).

### Search & Location Omnibar
- Floating elevated pill input with left-aligned location pinning, vertical micro-divider, keyword search prompt, and a trailing circular search button.

### Form Inputs & Selectors
- Default border `1.5px solid #E2E8F0` on white background. Focus rings transition smoothly to `0 0 0 3px rgba(37, 99, 235, 0.15)` with a `#2563EB` border.
